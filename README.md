# **Factory Equipment Performance and Failure Analysis**



#### **Project Overview**

This project performs Exploratory Data Analysis (EDA) on factory equipment data using Python. The objective is to identify equipment failure patterns and understand the relationship between sensor readings, operating conditions, and equipment performance.



#### **Tools and Technologies**

* \- Python
* \- Pandas
* \- NumPy
* \- Matplotlib
* \- Seaborn
* \- Jupyter Notebook



#### **Analysis Performed**

* \- Data cleaning and preprocessing
* \- Missing value and duplicate analysis
* \- Fault analysis by load type
* \- Failure type distribution
* \- Device-wise fault analysis
* \- Temperature and vibration analysis
* \- Power consumption analysis
* \- Correlation analysis
* \- Daily fault trend and rate analysis



#### **Key Findings**

* \- Overall fault rate: 3.28%
* \- Most common failure type: Vibration (28.05%)
* \- Highest device fault rate: IoT-M08 (4.40%)
* \- Maximum Load recorded the highest load-wise fault rate (4.06%).
* \- Current and power consumption showed a strong positive correlation (0.96).



#### **Conclusion**

The analysis identifies important patterns in factory equipment performance and failure behaviour. These findings can support equipment monitoring and preventive maintenance decisions.
